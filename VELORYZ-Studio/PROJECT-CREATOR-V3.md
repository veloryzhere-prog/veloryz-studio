# VELORYZ Project Creator V3 — operating guide

Project Creator V3 lives at /create/. It offers 12 original VELORYZ starter concepts, 26 credited external inspiration links to Framer/Webflow, 16 optional app and website capabilities, conditional requirements, a five-stage configurator, and a 4-page downloadable planning proposal.

## Visitor workflow
1. Discover: pick project category, page count and an optional starter.
2. Inspiration: browse, search and filter categories. External references always link to the original creator; an external template license is NOT included.
3. Capabilities: configure content, commerce, operations, apps and advanced integration requirements. Advanced items are marked for studio scope review.
4. Investment: choose preferred budget, launch window and project priority. Estimate reacts to pages and selected features.
5. Send brief: review the proposal, provide required name, email, goal and consent, and submit to /api/enquiries. A reference number is returned; no invitation is sent automatically.

## Admin pricing
In Studio Control → Settings, edit four values under Project Creator pricing assumptions: starting allowance (default INR 17,999), extra page (INR 1,500), standard feature allowance (INR 2,500), and upper-range contingency (25%). Save draft, then publish. Values are validated by the CMS before publishing. Some advanced capabilities use separate allowances and always need a detailed studio quote. Estimates never constitute a binding offer.

## Owner enquiry and portal
Creator V3 submissions appear in Studio Control → Project console with a readable overview of template, visual language, pages, features, timeline, preferred budget and goal. Open Create client workspace to prefill the client's name, verified invitation email and project description. The owner alone issues secure private portal invitations. A submitted brief is not a confirmed booking, signed contract or client account.

## PDF
Creator V3 downloads a 4-page PDF from the browser: direction, budget assumptions, roadmap and detailed capabilities. Legacy callers receive the original 3 pages. External preview illustrations are original VELORYZ styling, not screenshots or proprietary source from marketplace templates.

## Drafts, safety and rollout
Drafts stay only within the current browser tab, old planner drafts migrate, and submitted contact drafts are cleared after success. Never claim official quotation approval, payment or guaranteed availability from the calculator. Production screenshot testing and live enquiry delivery remain to be verified after hosting deploys latest main. Original homepage / Playground V-shaped structures are untouched.
