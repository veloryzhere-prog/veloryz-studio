# R50 — Client Workspace 3.0

Existing invitation sessions, milestones, owner approval requests, private messages and PDFs remain. Owners can upload PDF, PNG, JPEG and UTF-8 TXT files up to 2 MiB (20 per project target cap), stored in a private Supabase bucket and downloaded through project-scoped authenticated routes. Signature checks and attachment-only delivery are not malware scanning. External URLs remain subject to their provider’s permissions. Removal hides the item immediately; storage cleanup failure is explicitly reported. Review decisions and audit messages are recorded transactionally; change requests require feedback. Payments show existing request records joined to the authenticated project’s accepted enquiry reference, with no payment tokens or new checkout. Handover readiness is derived from real milestone, deliverable and approval states. Background refresh avoids replacing active text drafts and AI conversations. Existing encrypted AI archive is retained. No real customer record has been changed by this rollout.

Production acceptance requires authenticated owner/client upload/download tests, cross-project denial, actual payment reconciliation, and real invitation/mail verification. No payment is collected by this feature.
