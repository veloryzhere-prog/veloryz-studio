# VELORYZ Future Assets — integrated original Figma Make asset library

This directory includes the **100 actual animated SVG graphics** from the uploaded "VELORYZ Living Knowledge System" Figma Make export, retained in ten asset families. Files are served from `/assets/future-assets/{family}/{name}.svg` and intentionally use the original source paths, strokes, and animation rules.

Each SVG has embedded `prefers-reduced-motion` support. For accessible page rendering use `<img alt="">` for decorative graphics and avoid moving animation near reading-intensive prose.

`catalog.json` enumerates all file names and paths for optional usage in other Studio experiences. **The original brand logo is never replaced by the generic placeholder from the Figma Make export.**

These are small abstract animated SVGs suitable for accents, article category illustrations, feedback, status and loading states. They are not photographs or full-page mockups.
